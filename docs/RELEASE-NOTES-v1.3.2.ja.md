# Eikura v1.3.2

Eikura 1.3.2 では製品ブランドを **Eikura** に統一します。

## 変更点
- アプリのタイトル、About、3 言語リソース、ユーザー向け表示を Eikura に統一。
- プロジェクトサイト、プライバシー/サポート、README、ブランド規約を Eikura に更新。
- GitHub のワンクリック版は `Eikura-v1.3.2-x64-one-click.zip` を使用します。一方、Eizo 1.3.1 の内蔵アップデーターが改名版をそのまま検出できるよう、1.3.2 の唯一の MSIXBundle 技術アセット名は互換用に `Eizo_1.3.2.0_x64.msixbundle` を一時的に維持します。インストール後の製品名は Eikura です。
- MSIX Identity やローカルデータパスなど一部の旧技術識別子を互換レイヤーとして保持し、実際の署名済みパッケージによる 1.3.1 → 1.3.2 更新テストで設定・ライブラリ・再生履歴の保持を確認。
- Bangumi OAuth に `eikura://` の新しい主コールバックを追加し、`eizo://` も互換用に維持。新 Eikura Worker が有効でない場合は旧 Worker へ自動フォールバックします。

## 互換性
`Eizo_1.3.2.0_x64.msixbundle`、MSIX Identity、旧データパス、一部のランタイム識別子は 1.3.2 の移行互換性のためだけに残ります。現在の製品ブランドは Eikura であり、以後の新しい配布アセットは Eikura 命名へ戻ります。
