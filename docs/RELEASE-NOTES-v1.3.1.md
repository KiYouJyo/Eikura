# Eizo v1.3.1

发布日期：2026-09-27

## 启动加载视觉优化

- 将应用内启动页 Logo 下方的原生 `ProgressRing` 替换为宽 72、厚 2 的细型不确定进度 `ProgressBar`。
- 加载条前景改用 WinUI 3 主题资源 `TextFillColorSecondaryBrush`，会随浅色/深色模式自动切换，不再固定使用 Windows 蓝色强调色。
- 加载条轨道背景设为透明，减少启动页上的第二视觉中心，让 Logo 保持主体地位。
- 保持既有启动初始化顺序与延迟加载逻辑不变；本版本仅调整启动加载提示的视觉呈现。
- 产品版本 / MSIX 版本更新为 1.3.1 / 1.3.1.0。
