# Eikura branding

## Canonical name

| Locale | Product name | Note |
| --- | --- | --- |
| zh-CN | Eikura | Use the canonical brand unchanged |
| ja-JP | Eikura | Use the canonical brand unchanged |
| en-US | Eikura | Canonical brand |

Eikura is the canonical user-facing product name across locales.

The main-window shell wordmark is a deliberate exception and is displayed as:

`Eikura  映蔵`

`映蔵` is a fixed companion wordmark in the top menu/title area only; it is not a localized replacement for the Eikura product name. Other current UI, package, website, documentation, and marketing surfaces should continue to use **Eikura** as the product name.

## Short positioning

简体中文：Eikura——为日本动漫、日剧而生的原生 Windows 影音库。

日本語：Eikura — 日本のアニメ・ドラマを中心に楽しむネイティブ Windows メディアライブラリ。

English: Eikura — A native Windows media library built with Japanese anime and drama in mind.

## Rules

- Write the canonical user-facing product name as **Eikura** in every locale.
- Do not translate or localize the Eikura brand.
- The top shell/menu wordmark must be **Eikura  映蔵**, preserving the previous dual-name visual structure.
- Do not use `映蔵` as a standalone product name elsewhere in the current UI or marketing surfaces.
- Legacy identifiers may remain only when required for upgrade, package identity, local-data, protocol, or component compatibility.
- Legacy compatibility identifiers must never be presented as the current product name.
- Do not position the product as anime-only; anime and Japanese drama are priorities, not hard limits.
