Eikura Privacy

隐私与数据プライバシーとデータPrivacy & data

Eikura 采用本地优先设计：本地媒体不会被上传到 Eikura 自有服务器。

Eikura はローカル優先です。ローカルメディアを Eikura 独自サーバーへアップロードしません。

Eikura is local-first. Local media is not uploaded to an Eikura-operated server.

本地保存ローカル保存Local storage

设置、窗口状态、媒体库索引、播放进度和应用运行所需的缓存会保存在本机。

設定、ウィンドウ状態、ライブラリ索引、再生進捗、動作に必要なキャッシュは端末内に保存されます。

Settings, window state, library indexes, playback progress, and operational cache are stored locally.

联网功能ネットワーク機能Network features

当你使用元数据、Bangumi、更新检查或配置的 WebDAV 来源时，应用会连接相应第三方服务或媒体来源。请求的目的仅与所启用的功能相关。

メタデータ、Bangumi、更新確認、設定済み WebDAV を利用する場合、対応する第三者サービスやメディアソースへ接続します。

Metadata, Bangumi, update checks, and configured WebDAV sources communicate with the corresponding third-party service or media source.

分析与广告分析と広告Analytics & advertising

当前版本不会自动向 Eikura 自有后台发送广告标识符或使用分析数据。

現在のバージョンは広告 ID や利用分析を Eikura 独自バックエンドへ自動送信しません。

The current version does not automatically send advertising identifiers or usage analytics to an Eikura-operated backend.
