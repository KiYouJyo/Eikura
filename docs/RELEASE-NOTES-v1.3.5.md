# Eikura v1.3.5

- 在“设置 → 常规”新增“配置备份与恢复”卡片，可选择已配置的 WebDAV 媒体来源作为备份位置。
- 新增版本化配置备份格式，备份媒体来源、应用内保存的 TMDB Token、其他 WebDAV 来源凭据、元数据设置、播放/字幕设置与外观设置。
- 整个备份包使用 PBKDF2-SHA256（210,000 次迭代）派生密钥并通过 AES-256-GCM 加密；备份密码不会保存到应用或 WebDAV。
- 当前备份目的地自身的 WebDAV 密码不会写入备份，避免恢复备份前反而必须先从该备份取回凭据的循环依赖。
- 恢复前新增确认步骤；跨设备恢复时不存在的本地目录会跳过并提示。
- 播放历史、媒体数据库、缓存、窗口尺寸与本地文件访问令牌不属于本次配置备份范围。
- 产品 / MSIX 版本更新至 1.3.5 / 1.3.5.0。
