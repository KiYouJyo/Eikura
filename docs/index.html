Eikura

一款面向 Windows 的原生个人影音库。优先优化日本动漫与日剧，并把本地 / WebDAV 媒体、真实元数据、播放、字幕、缓存与追番体验统一起来。

Windows 向けのネイティブ個人メディアライブラリ。日本アニメ・ドラマを優先し、ローカル / WebDAV、実メタデータ、再生、字幕、キャッシュ、視聴管理を統合します。

A native Windows personal media library optimized first for Japanese anime and drama, unifying local/WebDAV sources, real metadata, playback, subtitles, caching, and watch-state management.

围绕个人影音库构建個人メディアライブラリのためにBuilt around your personal media library

从文件识别到详情页、播放、字幕与远程缓存，尽量让每一步都保持在同一套 Windows 原生体验中。

ファイル認識から詳細、再生、字幕、リモートキャッシュまでを一貫した Windows ネイティブ体験にまとめます。

Recognition, details, playback, subtitles, and remote caching stay inside one native Windows experience.

01

媒体库与聚合ライブラリと集約Library & aggregation

本地与 WebDAV 来源、扫描、分类，以及作品 / 季 / 集的聚合展示。

ローカル / WebDAV、スキャン、分類、作品・シーズン・話数の集約。

Local/WebDAV sources, scanning, classification, and title/season/episode aggregation.

02

日本媒体优先识别日本メディア優先認識Japanese-first recognition

识别季、集、OVA/OAD/ONA/SP、发布组与技术标签，并尽量保留原生标题。

シーズン、話数、OVA/OAD/ONA/SP、リリースグループ、技術タグを判定。

Seasons, episodes, OVA/OAD/ONA/SP, release groups, and technical tags.

03

真实元数据実メタデータReal metadata

通过 TMDB、Bangumi 等补全海报、背景、简介、季度、剧集与演职人员。

TMDB、Bangumi などから画像、概要、シーズン、話数、キャスト・スタッフを取得。

Artwork, summaries, seasons, episodes, cast, and staff from providers such as TMDB and Bangumi.

04

播放与进度再生と進捗Playback & progress

LibVLC、续播、拖动、倍速、全屏、播放队列与详情页剧集进度。

LibVLC、レジューム、シーク、速度、全画面、キュー、話数ごとの視聴進捗。

LibVLC, resume, seek, speed, fullscreen, queues, and per-episode watch progress.

05

字幕体验字幕Subtitles

外挂 ASS/SSA/SRT、内封字幕统一渲染、双字幕与首选语言。

外部 ASS/SSA/SRT、内蔵字幕の統一表示、二重字幕、優先言語。

External ASS/SSA/SRT, normalized embedded rendering, dual subtitles, and preferred languages.

06

缓存与追番キャッシュと視聴管理Cache & tracking

远程视频下载、暂停/继续、离线播放，以及 Bangumi 日历、发现与收藏能力。

リモート動画のダウンロード、一時停止/再開、オフライン再生、Bangumi カレンダーとコレクション。

Remote downloads, pause/resume, offline playback, plus Bangumi calendar, discovery, and collections.

Recognition, metadata, playback, and the app shell keep clear boundaries. Components ship with the app; in-app updates update the application as a whole.
