# Eikura v1.3.3

## 更新内容

- 「ランキング・発見」の下部にあった「さらに読み込む」ボタンを廃止し、ページ下端付近までスクロールすると次のページを自動読み込みするようにしました。
- 「ランキング・発見」と「アニメ検索」の追加読み込み時に、読み込み中メッセージと ProgressRing を表示します。
- 上部タイトルバーのワードマークを `Eikura  映蔵` に戻しました。
- Eikura 1.3.2 で確立した MSIX、ローカルデータ、Bangumi OAuth、旧プロトコルの互換性を維持します。

## バージョン

- アプリ: 1.3.3
- パッケージ: 1.3.3.0
