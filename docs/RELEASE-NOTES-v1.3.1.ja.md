# Eizo v1.3.1

リリース日：2026-09-27

## 起動ローディング表示の改善

- アプリ内起動画面のロゴ下にあったネイティブ `ProgressRing` を、幅 72・高さ 2 の細い不確定 `ProgressBar` に置き換えました。
- 前景色は WinUI 3 の `TextFillColorSecondaryBrush` を使用し、ライト / ダークテーマに自動追従します。固定の Windows アクセントブルーは使用しません。
- トラック背景を透明にして、ロゴを主役にした軽量な起動画面にしました。
- 既存の起動初期化順序と遅延ロード処理は変更していません。本リリースは起動時のローディング表示のみを調整します。
- 製品 / MSIX バージョンを 1.3.1 / 1.3.1.0 に更新しました。
