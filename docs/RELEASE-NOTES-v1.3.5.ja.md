# Eikura v1.3.5

- 「設定 → 一般」に WebDAV 設定バックアップ / 復元カードを追加しました。
- メディアソース、TMDB 設定、メタデータ設定、再生・字幕設定、外観設定を移行できます。
- バックアップ全体を PBKDF2-SHA256 と AES-256-GCM で暗号化します。
- バックアップ先そのものの接続情報はバックアップ対象外とし、復元時の循環依存を避けます。
- 別端末に存在しないローカルフォルダーは復元時にスキップして通知します。
- 再生履歴、メディアDB、キャッシュ、ウィンドウサイズ、ローカルファイルのアクセス情報は今回の対象外です。
- 製品 / MSIX バージョンを 1.3.5 / 1.3.5.0 に更新しました。
