Eikura v{{DISPLAY_VERSION}} one-click 自签名安装引导包
====================================================

这是用于 GitHub 侧载的 x64 framework-dependent 安装引导包（MSIX {{PACKAGE_VERSION}}）。
它本身不包含 MSIXBundle，也不包含 Windows App Runtime。

安装步骤
--------
1. 下载后必须完整解压 ZIP，不能在压缩包预览中直接运行文件。
2. 双击“① 安装Eikura.cmd”。
3. 如本机尚未信任 Eikura 的测试证书，Windows 会请求一次 UAC，仅用于把随附公开 CER 导入 LocalMachine\TrustedPeople。
4. 安装脚本从 Eikura v{{DISPLAY_VERSION}} 的固定 GitHub Release 下载 MSIXBundle，并验证下载大小、SHA-256 与签名后再安装。

运行库
------
- 本安装引导包不附带 Windows App Runtime。
- 当前 v{{DISPLAY_VERSION}} 测试版本要求本机已经安装兼容的 Windows App Runtime 1.8 x64。

安全边界
--------
- ZIP 中只包含公开 CER，不包含 PFX、P12、私钥或证书密码。
- 测试证书只导入 LocalMachine\TrustedPeople，不导入 Trusted Root。
- 安装脚本不会关闭 Windows 安全功能，也不会修改全局 PowerShell 执行策略。
- 应用 MSIXBundle 必须同时通过 SHA-256 和 CN=AppPublisher 签名验证。

卸载
----
双击“② 卸载Eikura.cmd”。它会卸载当前用户的 Eikura，并删除该侧载包对应的 TrustedPeople 测试证书。

项目仓库与 Release 资产均不包含签名私钥。
